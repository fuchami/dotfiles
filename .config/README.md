# dotfiles

## yadm

dotfilesはyadmを使って管理。

### Usage

```
# invoke lazygit
$ yadm enter lazygit

```

## Zsh

`/etc/zshenv` に以下を記載する必要がある。

```sh
ZDOTDIR=$HOME/.config/zsh
```

## NeoVim

AstroNvimを利用しており、別リポジトリで管理している。
